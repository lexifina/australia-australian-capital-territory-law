# 6 Meaning of agent
(1) For this Act, a person is an agent for a licensed provider if he or she carries out, whether within or outside the ACT, any specified function on behalf of the licensed provider.
(2) For this Act, a person is an agent for an external provider if he or she carries out, within the ACT, any specified function on behalf of the external provider.
(3) In this section:
specified function means—
  (a) registering a player; or
  (b) establishing a player’s account; or
  (c) accepting a deposit for, or authorising a withdrawal from, a player’s account; or
  (d) carrying out any other function that is classified as an agency function by the regulations.
