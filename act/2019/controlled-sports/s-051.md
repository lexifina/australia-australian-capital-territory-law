# 51 Offences—registered promoter at registered event in breach of approved code of practice
(1) A person commits an offence if the person—
  (a) is the registered promoter for a registered event; and
  (b) engages in conduct that fails to comply with a requirement of an approved code of practice; and
  (c) is reckless about whether the conduct complies with an approved code of practice.
Maximum penalty: 200 penalty units, imprisonment for 6 months or both.
(2) A person commits an offence if the person—
  (a) is the registered promoter for a registered event; and
  (b) fails to comply with a requirement of an approved code of practice.
Maximum penalty: 50 penalty units.
(3) An offence against subsection (2) is a strict liability offence.
