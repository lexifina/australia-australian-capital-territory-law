# 69 Offence—conduct non-registrable event in breach of approved code of practice
(1) A person commits an offence if—
  (a) the person conducts a non-registrable event; and
  (b) the event has been approved by an authorised controlled sports body; and
  (c) the person fails to comply with a requirement of an approved code of practice.
Maximum penalty: 50 penalty units.
(2) An offence against this section is a strict liability offence.
