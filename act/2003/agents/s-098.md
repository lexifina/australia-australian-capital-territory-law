# 98 Lending registration certificate
(1) A registered assistant property agent commits an offence if the assistant property agent lets out, hires or lends the assistant property agent’s registration certificate to someone else.
Maximum penalty: 100 penalty units.
(2) A registered assistant property agent commits an offence if the assistant property agent lets someone else use the assistant property agent’s registration certificate.
Maximum penalty: 100 penalty units.
(3) An offence against this section is a strict liability offence.
(4) If a court convicts a registered assistant property agent of an offence against this section, the assistant property agent’s registration is cancelled under this section.
