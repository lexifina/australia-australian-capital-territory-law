# 198 Additional contents of search warrant applications
(1) If the person applying for a search warrant suspects that it will be necessary to use firearms in executing the warrant, the person must state the suspicion, and the grounds for the suspicion, in the application.
(2) If a person applying for a warrant to search premises has previously applied for a warrant for the same premises, the person must, in the application, include particulars of the earlier application and its outcome.
