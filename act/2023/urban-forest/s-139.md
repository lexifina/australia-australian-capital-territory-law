# 139 Code of practice—protected tree disputes
(1) The Minister may approve a code of practice for dealing with protected tree disputes.
(2) For subsection (1), a dispute is a protected tree dispute if the dispute—
  (a) is between the lessees of 2 or more adjoining leases in a residential area; and
  (b) relates to a protected tree whose protection zone crosses a common boundary between the leases.
(3) A code of practice is a disallowable instrument.
(4) In this section:
residential area means an area in a zone identified in the territory plan as a residential zone (RZ).
