# 61 Failure to comply with approved code of practice
(1) A professional engineer commits an offence if—
  (a) an approved code of practice applies to the engineer; and
  (b) the engineer fails to comply with a requirement of the approved code of practice; and
  (c) the engineer is reckless about whether the conduct complies with the approved code of practice.
Maximum penalty: 50 penalty units.
(2) A professional engineer commits an offence if—
  (a) an approved code of practice applies to the engineer; and
  (b) the engineer fails to comply with a requirement of the approved code of practice.
Maximum penalty: 30 penalty units.
(3) An offence against subsection (2) is a strict liability offence.
