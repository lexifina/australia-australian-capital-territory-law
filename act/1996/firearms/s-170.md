# 170 User registration—decision
On an application for registration as a user of a firearm, the registrar must register the user unless prevented from doing so by this Act.
Note 1 For when the registrar must refuse to register a person as a user of a firearm, see s 171.
Note 2 A reference to an Act includes a reference to the statutory instruments made or in force under the Act, including any regulation (see Legislation Act, s 104).
