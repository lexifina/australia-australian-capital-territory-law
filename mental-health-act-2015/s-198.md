# 198 Approved code of practice
(1) The chief psychiatrist may approve a code of practice to provide guidance on assessing whether a person has decision-making capacity.
Note Power given under an Act to make a statutory instrument (including a code of practice) includes power to amend or repeal the instrument (see Legislation Act, s 46 (1)).
(2) An approved code of practice may apply, adopt or incorporate an instrument as in force from time to time.
(3) An approved code of practice is a notifiable instrument.
Note A notifiable instrument must be notified under the Legislation Act.
