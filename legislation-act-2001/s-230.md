# 230 Application of pt 19.4 generally
(1) This part applies if a law authorises or requires an entity (the appointer) to delegate (or subdelegate) a function.
Note Function is defined in the dict, pt 1 to include authority, duty and power.
(2) For subsection (1), if a law gives a function to an entity, the law may be taken to authorise the delegation of the function even if the law provides for another way in which the function may be exercised.
