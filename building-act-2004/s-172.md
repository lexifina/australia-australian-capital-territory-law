# 172 Australian Capital Territory Appendix to the Building Code of Australia
(1) In section 136:
Australian Capital Territory Appendix to the Building Code of Australia includes the latest Australian Capital Territory Appendix to the Building Code of Australia made under the Building Act 1972 (repealed).
(2) This section is a law to which the Legislation Act, section 88 (Repeal does not end effect of transitional laws etc) does not apply.
(3) This section expires on the day this subsection commences.
