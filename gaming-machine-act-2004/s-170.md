# 170 Corporations with gaming machines at multiple clubs
(1) This section applies if a corporation—
  (a) is a class C licensee; and
  (b) operates multiple clubs; and
  (c) holds authorisation certificates for gaming machines at multiple clubs.
(2) In working out the community contributions for each club, common expenditure on behalf of the multiple clubs must be allocated between the clubs in proportion to the number of gaming machines operated at each club.
