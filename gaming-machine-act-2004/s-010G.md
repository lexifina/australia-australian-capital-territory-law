# 10G No applications for, or transfers of, authorisation certificates etc for certain licensees
(1) This section applies if a licensee has surrendered an authorisation certificate under section 10D.
(2) The licensee is not entitled to—
  (a) apply for an authorisation certificate under section 21 (Authorisation certificate for class C gaming machines—application); or
  (b) acquire an authorisation certificate from an outgoing licensee under section 37E (Transferring an authorisation certificate).
