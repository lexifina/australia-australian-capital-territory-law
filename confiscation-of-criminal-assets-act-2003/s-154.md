# 154 Transaction suspension orders—affidavit supporting application
(1) An application for a transaction suspension order must be supported by an affidavit of the applicant police officer stating—
  (a) the grounds for the officer’s suspicions; and
  (b) the account in relation to which the order is sought.
(2) The court may require the police officer to give additional information about the grounds on which the order is sought.
