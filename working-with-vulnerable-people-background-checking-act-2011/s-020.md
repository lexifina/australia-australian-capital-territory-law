# 20 Application for registration—withdrawal
(1) An applicant may withdraw an application at any time by written notice to the commissioner.
Note If a form is approved under s 69 for this provision, the form must be used.
(2) If an application is withdrawn the commissioner—
  (a) must tell the named employer (if any) that the application has been withdrawn; and
  (b) need take no further action on the application.
Note If an unregistered person engaging in a regulated activity under s 15 withdraws the person’s application for registration, the person commits an offence under s 13 if the person continues to engage in the activity.
