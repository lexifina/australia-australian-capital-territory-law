# 97 Lending licence certificate
(1) A licensed agent commits an offence if the agent lets out, hires or lends the agent’s licence certificate to someone else.
Maximum penalty: 100 penalty units.
(2) A licensed agent commits an offence if the agent lets someone else use the agent’s licence certificate.
Maximum penalty: 100 penalty units.
(3) An offence against this section is a strict liability offence.
(4) If a court convicts a licensed agent of an offence against this section, the agent’s licence is cancelled under this section.
