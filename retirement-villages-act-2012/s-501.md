# 501 Existing residence contracts to be residence contracts
(1) This section applies if, immediately before the commencement day, an existing residence contract was in force.
(2) The existing residence contract is, on the commencement day, taken to be a residence contract—
  (a) in the same terms as the existing residence contract; and
  (b) subject to the same conditions as the existing residence contract.
(3) This section is subject to section 502 and section 503.
