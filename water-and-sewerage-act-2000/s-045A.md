# 45A Meaning of plumbing code
(1) In this Act:
plumbing code means the ACT plumbing code as affected by subsection (2).
(2) The plumbing code is taken to be amended to the effect that a hot-water system in a class 1 building must comply with the standard prescribed by regulation.
(3) In this section:
class, of building—see the Building Act 2004, dictionary.
