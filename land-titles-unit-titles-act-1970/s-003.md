# 3 Interpretation for Act
(1) In this Act:
graphic bar scale means a set of marks on a plan, at measured distances on a line, which indicates the scale to which the plan is drawn.
Land Titles Act means the Land Titles Act 1925.
(2) Where an expression used in this Act is defined in the Unit Titles Act 2001, that expression as so used has the same meaning as in that Act.
