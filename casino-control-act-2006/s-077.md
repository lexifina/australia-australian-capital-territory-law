# 77 Complying with control procedures
(1) The casino licensee commits an offence if the licensee contravenes the control procedures.
Maximum penalty: 50 penalty units.
(2) An agent of the casino licensee commits an offence if—
  (a) the agent operates, or performs a function in relation to, the casino; and
  (b) the agent contravenes the control procedures.
Maximum penalty: 50 penalty units.
(3) An offence against subsection (1) or (2) is a strict liability offence.
(4) A casino employee commits an offence if—
  (a) the casino employee performs a function in relation to the casino; and
  (b) the casino employee engages in conduct that contravenes the control procedures.
Maximum penalty: 10 penalty units.
