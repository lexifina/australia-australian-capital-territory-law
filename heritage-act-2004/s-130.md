# 130 Objects on old heritage objects register
(1) An object included in an old heritage objects register is taken to be registered under division 6.2.
(2) The details entered in an old heritage objects register for an object are taken to be the registration details for the object.
(3) Subsection (2) does not apply to any requirement stated in an old heritage objects register for the conservation of the heritage significance of the object.
(4) To remove any doubt, the council may amend the heritage register to reflect the operation of this section.
