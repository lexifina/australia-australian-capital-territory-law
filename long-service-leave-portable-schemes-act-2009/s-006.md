# 6 What is a covered industry?
Each of the following is a covered industry:
  (a) the building and construction industry;
  (b) the contract cleaning industry;
  (c) the community sector industry;
  (d) the security industry.
Note 1 Building and construction industry—see sch 1, s 1.3.
Note 2 Contract cleaning industry—see sch 2, s 2.3.
Note 3 Community sector industry—see sch 3, s 3.3.
Note 4 Security industry—see sch 4, s 4.3.
