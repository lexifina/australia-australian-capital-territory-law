# 144 Applications for builders’ licences under Building Act
(1) This section applies if, immediately before commencement day, a person had applied under the Building Act, section 15 for a builder’s licence, but the application had not been decided.
(2) The application is taken to be an application for a builders licence made under this Act.
(3) If, because the application was made under the Building Act, the application does not include something that is required for an application under this Act, the registrar may ask the applicant for the further information.
(4) If the application is for a licence, or a class of licence, that does not exist, the registrar may grant the applicant a licence that corresponds to the licence applied for, if satisfied that it is appropriate to do so.
